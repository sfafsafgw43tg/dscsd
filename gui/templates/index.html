Quick Guide & Troubleshooting

                
            

            

                

                    

                        
01

                        
Hands-Free Launch Pipeline

                        
Clicking Launch automatically boots your AVD with -writable-system, runs adb root, rewrites 22+ hardware ro.* properties via resetprop-rs + soft zygote reload, applies system settings, and attaches Frida runtime hooks.

                    


                    

                        
02

                        
Use Google APIs (Not Play Store)

                        
Always choose Google APIs when creating a device. Play Store images are production user builds that block adb root, preventing hardware property spoofing and Frida injection.

                    


                    

                        
03

                        
Verify & Inspect Every Prop

                        
Each running card displays live verification pills (e.g. ✓ 22/22 props, ✓ Root, ✓ Hooks). Open Details to inspect individual getprop values, copy device identifiers, tweak cameras, or read the emulator log.

                    


                    

                        
04

                        
Quick Troubleshooting

                        
If an emulator shows offline or fails to connect, open Settings → Repair ADB or run Doctor for an instant environment check. Use webcam0 in Cameras to stream your real webcam.
